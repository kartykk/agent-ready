# ask-when-blocked

Ask when:

- GOAL.md / STATUS.md / the user disagree
- two implementations are both valid
- you would delete or move a lot of files
- you would `git push`, deploy, or migrate data
- a secret or production URL is required

Ask **one** question. Then wait. Do not keep coding behind a guess.
