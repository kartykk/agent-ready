# debug-with-evidence

1. Write down the **symptom** (command + output, or screenshot text).
2. Reproduce. If you cannot, say so and stop guessing.
3. Find the code that actually ran (not a similar file).
4. One hypothesis. One small experiment or log.
5. Smallest fix. Add a regression test if the project has tests.
6. Re-run the same reproduction. Paste proof.

Do not “try a rewrite” as step 1.
