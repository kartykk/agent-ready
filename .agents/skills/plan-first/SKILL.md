# plan-first

Do **not** edit product code yet.

Write in the work folder (or the reply):

1. **Goal** — one sentence, what done looks like.
2. **In scope** — files/folders allowed.
3. **Out of scope** — do not touch.
4. **Steps** — 3–7 checkboxes.
5. **Proof** — command that must pass.

If two designs are reasonable, **ask** and stop. Do not pick in silence.
