# start-session

1. Read `AGENTS.md`, `GOAL.md`, `ARCHITECTURE.md`, `STATUS.md`, `NOW.md`, `LEGACY.md`, `.agents/CONTINUE.md`.
2. If STATUS disagrees with any other file, follow STATUS.
3. If the user path is in LEGACY.md, stop.
4. Read `.agents/work/BOARD.md`. If a row is `doing` and you are not the owner, do not steal it — handoff or pick another `open` row.
5. If the task is not obvious, open `.agents/skills/CATALOG.md` and load **one** matching skill.
6. Reply with: current NOW line, the BOARD row you will take, and nothing else until the user adds work.
