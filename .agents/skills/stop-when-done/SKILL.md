# stop-when-done

When the BOARD item’s checkboxes are done and `verify-change` passed:

1. Update `NOW.md`.
2. `done-commit` if you should commit.
3. Reply with **one** next action for the **human**.
4. **Stop.** Do not open a second feature, “quick cleanup”, or extra files.
