# take-work

1. Open `.agents/work/BOARD.md`.
2. Pick one `open` row, or continue your `doing` row.
3. Set `Owner` to your agent name (`grok` / `claude` / `cursor` / `gemini`).
4. Set `Status` to `doing`.
5. Create or open `.agents/work/W-NNN-*/tasks.md` and check the first box you will do.
6. Update `NOW.md` **In flight** to that ID.

Do not take two rows. Do not clear another owner’s `doing` row.
